sentinelai — CLI-Based Scans & Remediation Guide
PyPI: nitaanth-sentinelai Accepted · Springer ICDECT-2026

Complete reference guide to running automated multi-tool AST security audits, Llama 3.3-70B AI explanations via Groq, interactive AST patching, report exports, and CI/CD quality gating with SentinelAI.

01

1. One-Time Setup (On Any Machine)

Installs the package globally via pip. Now sentinelai is available globally in your terminal.

$ pip install nitaanth-sentinelai
02

2. Basic CLI Scan (Core Scanners)

Runs Semgrep, Bandit, and GitLeaks, correlates findings, and shows the terminal summary:

# Scan the current directory
$ sentinelai scan .
# Scan a specific repository or folder
$ sentinelai scan sentinelai-manual-test
03

3. CLI Scan with AI Insights (Groq LLM)

Uses Llama 3.3-70B on Groq to explain vulnerabilities and recommend root-cause fixes:

# Set your API key
$ export GROQ_API_KEY="your-groq-key"          # macOS/Linux
PS> $env:GROQ_API_KEY="your-groq-key"           # Windows PowerShell
# Run scan with Groq
$ sentinelai scan . --ai-provider groq --egress allow
04

4. Interactive Vulnerability Remediation (fix & undo)

Interactively reviews detected security flaws, previews AST syntax-validated diffs, and prompts to apply fixes:

# Interactively fix detected issues
$ sentinelai fix .
# Revert / rollback the last fix session
$ sentinelai undo
05

5. Generate Reports

Export audit findings in HTML for visual review, SARIF for GitHub & IDEs, JSON for pipelines, or Markdown for PRs:

# HTML interactive report (best for visual review)
$ sentinelai scan . --format html -o report.html
# SARIF format (for GitHub Security tab / VS Code / IDEs)
$ sentinelai scan . --format sarif -o results.sarif
# JSON format (for automated scripts / pipelines)
$ sentinelai scan . --format json -o scan-result.json
# Markdown report (for PR comments / documentation)
$ sentinelai scan . --format markdown -o report.md
06

6. Filter by Severity & CI/CD Pipeline Gating

Target specific severities or fail automated build pipelines when critical flaws are found:

# Only show High and Critical findings in terminal
$ sentinelai scan . --severity high
# Break the build / exit code 1 if High or Critical issues exist (CI gate)
$ sentinelai scan . --fail-on high
